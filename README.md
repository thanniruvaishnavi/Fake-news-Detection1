# Fake News Detection 📰

A web application that detects whether a piece of news is real or fake using a machine learning model. Built with a modern React + TypeScript frontend and deployed on Vercel.

## Features

✨ Key Features:

🔍 Detects fake vs real news from input text
⚡ Fast, modern frontend built with Vite
🎨 Clean UI styled with Tailwind CSS
🚀 Deployed live on Vercel

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- Bun (package manager)

## Getting Started

### Prerequisites

- Node.js or Bun installed

### Quick Setup

```bash
git clone https://github.com/thanniruvaishnavi/Fake-news-Detection1.git
cd Fake-news-Detection1
bun install
```

### Running the App

```bash
bun run dev
```
